# Optical Waste Sorting System
Welcome to the Optical Waste Sorting System repository! We are a group of aspiring developers and AI enthusiasts from the SKN D&A (Data & AI) research circle at the PK Cracow University of Technology.

## About the Project
---

This project marks our first steps into the world of Computer Vision and Artificial Intelligence. Our mission is to build a system capable of assisting in waste management by automatically identifying and sorting recyclables through image analysis.

Currently, we have implemented the initial sorting logic, which serves as the core foundation for our future real-time object detection models.

## Key Achievements
---

+ Environment setup and project structure.

+ Implementation of the basic sorting algorithm (initial classification).

+ Successful repository initialization.

## Roadmap
---

+ Expand the training dataset with diverse waste categories.
  
+ Improve model accuracy through fine-tuning.
